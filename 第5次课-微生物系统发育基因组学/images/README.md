# 第5次课 SVG 图片说明

本目录包含第5次课"微生物系统发育基因组学"理论课件中使用的所有SVG图表。

## 图片列表

### 1. genome_vs_single_gene.svg
**用途**: 比较全基因组系统发育与单基因系统发育的差异
**内容**: 
- 左侧展示16S rRNA单基因方法的局限性
- 右侧展示全基因组方法的优势
- 包含信息量、分辨率和方法特点的对比

### 2. algorithm_flowchart.svg  
**用途**: 展示全基因组系统发育分析的完整流程
**内容**:
- 从基因组序列输入到发散时间估算的6个主要步骤
- 每个步骤对应的主要软件工具
- 清晰的流程箭头指示

### 3. strict_molecular_clock.svg
**用途**: 说明严格分子钟模型的基本概念
**内容**:
- 时间轴和系统发育树的结合展示
- 等长分支表示恒定进化速率
- 包含4个物种的简单系统发育关系

### 4. gene_species_tree_conflict.svg
**用途**: 展示基因树与物种树之间的拓扑冲突
**内容**:
- 左侧为物种树拓扑结构
- 右侧为基因树拓扑结构  
- 中间冲突标识和可能原因说明

### 5. phylogenetic_network.svg
**用途**: 对比传统树形结构与系统发育网络
**内容**:
- 左侧传统二叉树结构
- 右侧包含水平基因转移的网络结构
- 图例说明垂直遗传和水平转移

### 6. genome_rearrangement_types.svg
**用途**: 展示主要的基因组重排类型
**内容**:
- 原始基因组作为参考
- 倒位、易位、重复、缺失四种重排类型
- 每种类型的具体变化用不同颜色标识

## 设计特点

- **统一风格**: 所有图片采用一致的颜色方案和字体
- **教学导向**: 重点突出关键概念和对比关系
- **清晰易读**: 适合课堂投影和打印使用
- **矢量格式**: SVG格式保证在任何尺寸下都清晰显示

## 使用说明

这些SVG文件可以：
- 直接在现代浏览器中查看
- 嵌入到Marp课件中使用
- 转换为其他格式（PNG、PDF等）
- 在各种演示软件中使用

## 技术规格

- **格式**: SVG (Scalable Vector Graphics)
- **尺寸**: 根据内容优化，通常为500-800像素宽
- **兼容性**: 支持所有现代浏览器和演示软件
- **文件大小**: 每个文件通常小于10KB
