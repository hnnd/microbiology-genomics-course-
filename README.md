# 微生物基因组学课程

## 课程概述

本课程为微生物学专业研究生课程，共8次课，每次课包含2小时理论课和2小时实践操作。

## 课程结构

- **总学时**: 32学时（8次课×4学时）
- **理论学时**: 16学时
- **实践学时**: 16学时
- **课程周期**: 8周

## 目录结构

```
microbiology-genomics-course/
├── 第1次课-微生物基因组学概论与进化/
├── 第2次课-基因组组装策略与评估/
├── 第3次课-基因预测与功能注释系统/
├── 第4次课-比较基因组学与泛基因组/
├── 第5次课-微生物系统发育基因组学/
├── 第6次课-微生物代谢网络重建/
├── 第7次课-功能基因挖掘与应用/
├── 第8次课-微生物群落基因组学/
└── 课程资源/
```

## 文件命名规范

- 理论课件：`理论课件-[主题名称].md`
- 实践操作：`实践操作-[具体内容描述].md`
- 目录命名：`第X次课-[主要主题]`

## 使用说明

每个课程目录包含：
1. 理论课件（Marp格式）- 2小时教学内容
2. 实践操作指南（Markdown格式）- 2小时实践内容

## 技术要求

- Marp用于课件演示
- Markdown用于操作指南
- 支持代码语法高亮
- 支持数学公式和图表
